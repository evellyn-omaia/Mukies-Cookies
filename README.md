# Mukies Cookies

O Mukies Cookies será um sistema desenvolvido para ajudar pequenos vendedores de cookies a organizar seus produtos e pedidos de forma simples.

No sistema, será possível cadastrar os sabores de cookies, definir preços, organizar os produtos por categorias e informar se estão disponíveis para venda.

Também será possível registrar pedidos informando o nome do cliente, os produtos escolhidos, a quantidade, a data de entrega e o status do pedido.

O projeto será desenvolvido como uma **Web API utilizando .NET 8, Entity Framework Core e SQL Server**.

A aplicação contará com quatro entidades principais:

* Categorias;
* Produtos;
* Pedidos;
* Itens do pedido.

O sistema terá relacionamentos entre as entidades, operações de cadastro, consulta, edição e exclusão, filtros de pesquisa e dados iniciais para facilitar os testes.

O objetivo é criar uma API simples, organizada e útil para o controle das encomendas de um pequeno vendedor de cookies.
